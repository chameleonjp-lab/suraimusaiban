# スライダーとスライムの動作修正

ユーザーの依頼は、2段の数字ボタンを自由に動かせるスライダーへ変更し、スマートフォンでスライムをThree.jsで動かすこと。

- 回答は横1本のnative range。既存の−5〜−1・＋1〜＋5を保持し、中央0は未選択として集計へ送らない。選択値・方向・強さを表示。ドラッグ中にinputを置換せず、タッチとキーボードに対応する。
- Three.jsの実モデルを使い、通常時は自動で呼吸・揺れ・しずくを動かす。見分けやすい動きに調整する。
- OSの省モーション設定は初期状態で尊重し、停止理由を表示する。「スライムを動かす」で明示的に再開した場合は、画面遷移やOS通知で再び止めない。手動停止も同じく維持する。
- WebGLが使えない・contextを失った場合は静止画と再試行表示に切り替える。再試行では新しいcanvasでThree.jsを初期化する。表示可能なcanvasの復帰も検証する。
- 個人情報・回答の保存方式、スコア式、DB・Edge・SNS画像は変更しない。

方式の判断: native rangeはブラウザ標準のドラッグ・キー操作が使える。独自pointer実装は採用しない。Three.jsは既存モデルと描画ループを修正し、静止画にCSSの動きを付ける方式は採用しない。初期停止の原因は端末設定の可能性があり、実機設定は未確認。
