# 法廷と裁判画面の確認

2026-10-23 / Linux Chromium (Playwright 1.64.1)、SwiftShader。実機iPhone Safariは未確認。

ホームは暖かなアイボリー、濃紺の本文、ラベンダーの補助色を用いた物語の表紙として構成。法廷はHTML canvas内の3Dで、記録・主張・選択・送信状態は読み上げ可能なHTMLに置く。検察と弁護士は同じ面積と文字サイズで提示する。小画面で文字を200%にすると主張を縦に並べ、両者の可読性を保つ。

## 画像実見

以下の画像を実際に開いて確認した。縦横の本文・ボタンに横方向の欠けはなく、390pxで刑罰側5個／待遇改善側5個をそれぞれまとめる。200%文字表示では各符号群内で折り返す。200%時のヘッダー重なりを修正し、最終画像で重なりがないことを確認した。

通常の本文・注釈で使う `#6d6b77` は背景 `#f8f6ef` に対して4.83:1。手順説明 `#706878` は4.93:1。低コントラストだった説明・補助ラベル・フッターの色を濃くした。装飾の罫線や進捗バーは本文に数えない。

## 操作

`tests/e2e/courtroom.spec.ts` は390×844と844×390のホームから裁判への遷移、過去結果の入口がないこと、3D停止後にも回答できることを検証。`tests/e2e/trial.spec.ts` は20件すべてで負・正を選び直せること、19件で確定できないこと、一覧と最終確認、200%文字で横スクロールがなく44px以上の操作領域があること、下書きの再読込復元を検証する。

3D停止は無音の静止画描画に切り替える。prefers-reduced-motionを初期値として尊重する。WebGL失敗・context lossでは同一モデルから生成された静止素材へ切り替え、DOMの入力を維持する。結果は提出の応答を受けたときだけメモリ内に保持し、ホーム・別画面・再読み込み・BFCache復帰後は個人結果を復元しない。

未接続時は「プレビュー・未送信」と表示し、集計への寄与・実投票の完了・比較画像を偽装しない。プレビューの回答IDはタブ内に限り再利用する。
